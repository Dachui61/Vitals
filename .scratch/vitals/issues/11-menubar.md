# 菜单栏：图标、迷你读数与菜单

## Question

做出菜单栏入口：`MenuBarExtra` + 迷你读数 + 菜单。

要交付：

- 菜单栏图标上直接显示迷你读数：**CPU% + 核心温度 + 内存%**（温度不可用时降级显示热压力四档的缩写，不留空位）。**只显示核心温度**，不带 SoC 热点（票 04）。
- 图标形态：单色模板图（跟随系统深浅色），迷你读数以文字形式拼接，不能因长度变化导致菜单栏抖动（固定宽度/对齐策略要写清楚）。
- 点击弹出浮窗：点击菜单栏图标展开或收起悬浮窗；菜单里另有一份完整菜单。
- 菜单项：打开/收起悬浮窗、阈值设置入口（温度阈值、CPU 阈值）、**透明度滑块**（票 25：20%–100%，步长 5%，默认 100%，只作用于悬浮窗背景，文字始终不透明）、告警总开关、开机自启状态开关、"安装温度组件"入口（helper 未装时出现）、关于、退出。
- 设置类项（阈值、透明度、告警开关、开机自启）写入 `UserDefaults`，启动后保持；透明度滑块要**实时生效**（拖动时悬浮窗背景立刻变淡）。
- 数值刷新：迷你读数随采样 tick 更新，不因重建视图而闪烁或重置。

产出：实现 + 截图或录屏式说明（可用 `screencapture` 留档到 `docs/`）。
