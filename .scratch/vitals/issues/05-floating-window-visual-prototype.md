# 悬浮窗视觉与布局原型

## Question

浮窗长什么样？做一个粗糙但**可运行、可点击**的原型（SwiftUI + 假数据驱动，不需要接真实采集器），用于确定：

- 布局骨架：顶部状态条（CPU% / 温度 / 内存% / 电源状态）+ 每核曲线区（按 超频 2 / 性能 4 / 能效 6 三组着色）+ 告警色带与阈值刻度。
- 状态变体至少覆盖四种：正常、温度告警（黄/红）、温度不可用、helper 未安装（含"安装温度组件"的引导入口）。
- 窗口行为：默认尺寸、是否可缩放、隐藏标题栏、拖拽把手、置顶层级、多显示器上出现的位置。
- 中文文案与数字格式：温度整数还是一位小数、CPU 百分比是否取整、单位写法（°C / %）、"不可用"时的占位文案。

产出：原型源码作为本票的资产链接（放在 `research/` 或 `prototypes/` 目录下），并附一份简短的设计说明（各区域的作用与配色语义）。原型只求结构与手感，不求美观。
