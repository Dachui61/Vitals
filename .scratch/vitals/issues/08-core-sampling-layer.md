# 核心采样层实现与单元测试

## Question

在 `VitalsCore` 里实现 v1 各项指标的真实采集，并让纯逻辑部分有单元测试。

范围（依 03 的结论选定具体 API）：

- CPU：总量 + 每核占用（两次采样差分、平滑），并按 超频/性能/能效 分组标注核型。
- 内存：已用/总量/百分比、内存压力等级。
- 电源状态：交流电供电状态（本机无电池，不做电池百分比）。
- GPU 占用百分比（v2 指标的后端可先在 Core 里做好接口，UI 后接）。
- 采样器抽象：每个指标一个 provider 协议，失败时返回"不可用 + 原因"而不是抛异常或编造数值；便于单测注入假数据。
- **单元测试**（`VitalsCoreTests`）：CPU 差分算法（已知序列 → 已知百分比）、平滑与环形缓冲、速率计算、百分比格式化与温度格式化的边界值（不可用/负值/NaN）、核型分组映射。

约束：采样层不 import SwiftUI，不碰 UIKit/AppKit；不得 fork 子进程来取数（除 03 实测证明不可行且代价可接受）。

产出：实现代码 + 测试 + 每个采集后端的一页说明（数据来源、刷新代价、已知坑）。
