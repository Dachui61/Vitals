# 悬浮窗实现

## Question

按 05 原型的结构，做出真正的悬浮窗。

要交付：

- 独立 `NSWindow`（非 popover）：无标题栏、置顶（`.floating` 层级）、可拖拽、可移动到任意显示器、可显示/隐藏。
- 内容遵循 05 原型的布局：顶部状态条（CPU% / 温度 / 内存% / 电源状态）、每核曲线区（按 超频 2 / 性能 4 / 能效 6 三组着色）、告警色带与阈值刻度。
- 曲线用 SwiftUI Charts 或自绘（选定后全项目统一），60s 滚动窗口，10 分钟历史可选切换查看。
- 状态变体：正常 / 温度告警（黄/红）/ 温度不可用 / helper 未安装（含引导入口）。
- 细节：数字格式与 05 一致；窗口默认位置与尺寸；跨显示器移动后不跑飞；隐藏后不占活动空间。
- 手动验收按 `docs/acceptance.md` 的对应条目逐条勾。

产出：实现 + 验收勾选结果。
