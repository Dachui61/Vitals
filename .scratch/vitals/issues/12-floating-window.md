# 悬浮窗实现

## Question

按 **05 定稿的视觉规范**（原型与截图见 [prototypes/](../../prototypes/)）做出真正的悬浮窗。

**视觉规范（照做，不要自行发挥）**：

- **响应式分级（票 24 定稿，取代"固定八段布局"）**：宽、高各算一个允许的最高档，**取小者**为实际档位。
  - L0：宽度 < 320、高度 ≥ 46 → **一行文字** `CPU 13% · 温度 57° · 内存 63%`（标签次级色、数值主色、温度按阈值变色、分隔符「·」；L0 不显示标题栏）。
  - L1：< 520 / ≥ 120 → 小卡片 CPU · 核心温度 · 内存 · GPU 占用。
  - L2：< 700 / ≥ 200 → 小卡片 电源 · 磁盘 · 网络。
  - L3：< 880 / ≥ 400 → 核心温度卡（大数字 + SoC 热点 + 热压力等级 + 阈值带）。
  - L4：< 1080 / ≥ 660 → 进程 Top 5 卡片。
  - L5：≥ 1080 / ≥ 660 → 每核占用（12 条曲线）。
  - **高度不够就退档**，不允许内容被裁掉；滚动仅作兜底且隐藏滚动条。
- **每核曲线**：12 条并排迷你曲线，核型着色 **超频=橙红 / 性能=蓝 / 能效=绿**，每核下方标当前整数百分比，副标题"60 秒滚动窗口 · 颜色区分核型"。
- **数字格式**：详情区温度一位小数，顶部瓦片整数（58°），CPU/内存整数百分比，磁盘一位小数，网络整数 KB/s。
- **主题跟随系统浅/深**：用 SwiftUI `colorScheme` 派生一套语义色（背景/卡片/描边/主文/次文/警告黄/警告红），浅色下卡片白底。
- **窗口**：无边框、置顶 `.floating`、**可拖动到任意位置**、**可缩放到任意大小**；`minSize = 230×34`、`maxSize = 4000×3000`；**右下角加一个显式缩放握把**（无边框窗口的自带缩放光标不够明显）。
- **告警**：只改数字颜色（≥70 黄、≥80 红）+ 阈值带同步变色，**不改整个窗口配色**。
- **状态变体**：正常 / 温度告警 / 温度不可用（「不可用」+「macOS 未向无特权应用开放温度传感器」）/ 传感器识别中（进度条 +「正在识别温度传感器…」）。
- **档位切换**：瞬时替换，正式版用 0.15s 交叉淡化避免闪烁。
- **透明度（票 25 定稿）**：面板底色、卡片底色、描边统一乘一个透明度因子（**20%–100%，默认 100%**），**文字、数值、曲线、图标始终 100% 不透明**——背景透出桌面但数字依旧清晰。**不要用 `NSWindow.alphaValue`**（那是整窗一起变，文字会不可读）。L0 单行模式同样适用；档位切换时透明度不变。
- 原型里的底部控制栏（变体/外观切换器）**只属于原型**，正式版去掉。

实现要求：

- 独立 `NSWindow`（非 popover）：无标题栏、置顶（`.floating` 层级）、可拖拽、可移动到任意显示器、可显示/隐藏。
- 内容遵循上面的布局与配色；曲线复用 60s 滚动窗口，10 分钟历史可选切换查看。
- 数据从 provider 注入（原型是假数据）；曲线直接读 `VitalsCore` 的历史环形缓冲。
- 细节：窗口默认位置与尺寸；跨显示器移动后不跑飞；隐藏后不占活动空间。
- 手动验收按 `docs/acceptance.md` 的对应条目逐条勾。

产出：实现 + 验收勾选结果。

## Answer

**悬浮窗主体已实现**（`Sources/VitalsUI/VitalsPanel.swift`）：按票 05 的视觉规范 + 票 24 的响应式分级移植自原型。

- **响应式分级**：宽、高各算一个允许的最高档，取小者；L0 一行文字 / L1 三瓦片 / L2 加电源 / L3 加温度卡 / L5 加每核曲线；高度不够自动退档，内容用 `ScrollView` 兜底（隐藏滚动条）。
- 视觉：主题跟随系统浅/深、**背景透明度可调而文字恒不透明**（票 25）、每核 12 条曲线按核型着色、阈值带、核心温度大数字 + SoC 热点 + 热压力等级独立成行、不可用时显示原因而**不显示 0**、传感器名 + 「近似值」标注。
- 窗口：无边框、置顶、可拖动、可缩放（`minSize 230×34`），默认位置避开 Dock 与桌面小组件。

**尚未实现**（各自归票）：GPU/磁盘/网络瓦片与进程 Top 5 区块属 **票 19（v2 指标）**；右下角的显式缩放握把未加（原型里也没有，票 25 记录了这条要求，需在收尾时补）。
