# 验收清单

做完了没有，看这份清单。每条都给出**验证步骤**与**通过阈值**，不接受"看着差不多"。
勾选规则：✅ 通过 / ❌ 不通过（写进 `docs/acceptance-report.md`）/ ⏭ 跳过（写明原因）。

---

## A. 数据准确性

| # | 验收项 | 验证步骤 | 通过阈值 |
|---|---|---|---|
| A1 | CPU 总占用与系统一致 | 同时打开活动监视器与 Vitals，等 5 个采样周期，各取 5 次读数的中位数对比 | 差 ≤ 3 个百分点 |
| A2 | 每核占用合理 | `top -l 1 -stats pid,cpu` 对照单核读数 | 单核差 ≤ 5 个百分点；空闲核 < 5% |
| A3 | 核型分组正确 | 满载 12 核时，能效核曲线应明显低于超频核；对照 `sysctl` 的核数 | 分组数量 = 6/2/4，且与 `hw.perflevel*` 数量一致 |
| A4 | 核心温度有值且合理 | 空闲读一次 | 30–60 °C；必须同时显示「SMC <键名> · 近似值」 |
| A5 | 核心温度随负载上升 | 8 线程满载 60 s，观察核心温度 | 上升 ≥ 8 °C（票 23 实测 +12.8 °C） |
| A6 | 核心温度不超上限 | 满载 10 分钟后 | ≤ 90 °C |
| A7 | SoC 热点有值且更热 | 与核心温度同屏对比 | 空闲时 SoC 热点 ≥ 核心温度（本机实测 52–55 vs 44） |
| A8 | 温度不可用时不显示 0 | 临时改坏传感器名（把 `Tp0j` 改成 `Tp0ZZ`） | 显示「不可用 + 原因」，**不显示 0** |
| A9 | 内存口径正确 | 对照活动监视器的「已用内存」 | 差 ≤ 2%（口径 = App + Wired + Compressed；**不是** total−free−speculative） |
| A10 | 内存压力等级一致 | `sysctl kern.memorystatus_vm_pressure_level` 对照 | 等级文字一致 |
| A11 | swap 数值合理 | `sysctl vm.swapusage` 对照 | 差 ≤ 1 MB |
| A12 | 电源状态正确 | 对照 `pmset -g ps` | 显示「外接电源」 |
| A13 | 热压力等级一致 | 对照系统设置/活动监视器 | 四档文字一致，且**不叫"温度"** |
| A14 | GPU 占用（v2） | 跑一个 GPU 负载程序 | 与 AGX `Device Utilization %` 差 ≤ 10 个百分点 |
| A15 | 进程列表只含自己的进程 | 对照 `ps -u $USER` | 进程数与用户名一致，**不含系统进程** |

## B. 实时性

| # | 验收项 | 验证步骤 | 通过阈值 |
|---|---|---|---|
| B1 | 刷新间隔 | 盯住 CPU 数字变化 | 每秒变一次（1 Hz） |
| B2 | 数值不滞后 | 制造一次突发负载 | 界面数值落后真实值 ≤ 2 s |
| B3 | 曲线平滑 | 观察 60 s 滚动窗口 | 无跳变、无闪烁；相邻采样差 ≤ 25 个百分点（除非真实跳变） |
| B4 | 唤醒后恢复 | 睡眠 1 分钟后唤醒 | ≤ 3 s 内恢复采样，且不显示陈旧值 |
| B5 | 10 分钟历史可用 | 连续运行 10 分钟 | 可回看 10 分钟前的粗粒度数据 |

## C. 资源占用

| # | 验收项 | 验证步骤 | 通过阈值 |
|---|---|---|---|
| C1 | 常驻内存 | `ps -o rss -p <pid>` | ≤ 60 MB |
| C2 | 采样自身开销 | 空闲时看 Vitals 自己的 CPU 占用 | ≤ 0.5%（v1 全量采样实测约 12 µs/次） |
| C3 | 唤醒不活跃 | 空闲 10 分钟 | 不产生持续唤醒（不轮询屏幕/不 fork） |

## D. 行为

| # | 验收项 | 验证步骤 | 通过阈值 |
|---|---|---|---|
| D1 | 开机自启 | 重启机器 | 10 s 内菜单栏出现 Vitals 图标 |
| D2 | 菜单栏迷你读数 | 看菜单栏 | 显示 CPU% + 核心温度 + 内存%；与浮窗同一次快照数值一致 |
| D3 | 浮窗可拖动 | 拖到另一块显示器 | 位置跟随，无卡顿 |
| D4 | 响应式分级 | 缩到最小 / 拉到最大 | 按分档表增减内容；L0 只有一行字；**高度不够时自动退档**，内容不被裁切 |
| D5 | 透明度 | 菜单里拖滑块 | 20%–100% 连续可调；背景变淡而**文字清晰度不变** |
| D6 | 主题跟随系统 | 切换系统浅色/深色 | 悬浮窗跟着变 |
| D7 | 告警触发 | 把温度阈值调到低于当前温度 | ≤ 5 s 内发通知 |
| D8 | 告警不刷屏 | 保持在阈值以上 10 分钟 | 只发 1 次（冷却 10 分钟） |
| D9 | 告警可恢复 | 温度降回阈值以下再升上去 | 能再次触发 |
| D10 | 温度不可用时告警行为 | 破坏传感器名 | 温度类告警不触发，且界面说明原因；CPU 类告警仍正常 |
| D11 | 通知授权被拒 | 在系统设置里拒绝通知权限 | 降级为界面内提示，不崩溃 |
| D12 | 退出干净 | 退出后看进程 | 无残留进程 |
